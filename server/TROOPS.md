# Neon Dominion - Troops Guide

## Overview

Neon Dominion has 12 troop types. Units are trained in the Recruitment Core and consume population.

## Core Combat Notes

- Attack Power = sum of (unit attack stat x unit count)
- Defense Power = sum of (unit defense stat x unit count)
- Shield Grid gives +2% total defense per level
- Casualties are ratio-based with a random factor
- Overseer reduces control by 50 on a successful attack if it survives

## Troop Catalog

### Assault Trooper

- Role: Defensive frontline infantry
- Stats: Attack 30, Defense 40, Speed 18, Carry 15
- Cost: Biomass 30, Alloy 30, Ore 70, Population 1, Time 1m 19s
- Requirements: Recruitment Core Lv1

- Requirements: Recruitment Core Lv7, Command Core Lv6

### Overseer

- Role: Conquest / control unit
- Stats: Attack 0, Defense 30, Speed 15, Carry 0
- Cost: Biomass 300, Alloy 250, Ore 200, Population 5, Time 30m 0s
- Requirements: Recruitment Core Lv9, Command Core Lv8, Shield Grid Lv6
- Limit: Maximum 3 per nexus
- Notes:
  - Does not contribute attack damage
  - If every non-overseer unit dies, the overseer dies too
  - Each successful overseer strike reduces enemy control by 50
  - Overseers are consumed (lost) when they complete a conquest (control reaches 0)

## Conquest Flow

1. Train Overseer
2. Send Overseer with escort troops
3. Win battle with Overseer alive
4. Enemy control drops by 50
5. At control 0, ownership transfers

## Quick Recommendations

- Early defense: Lancer Drone + Assault Trooper
- Mid defense: add Bulwark Guard and Siege Mech
- Fast raid: Skimmer Bike + Recon Operative
- Heavy push: Siege Mech + Annihilator + escort
